# Harsh Tripathi — Portfolio

Professional minimalist compartmentalised portfolio for **Harsh Tripathi** (Associate MarTech Consultant at RightWave & Software Engineer).

## ✨ Key Features

- **Compartmentalised Bento Architecture**: Structured modular panels for Overview, Career & Academic Timeline, Interactive Competencies Matrix, Selected Projects, Credentials, and Direct Contact.
- **Nordic Slate & Indigo-Teal Design System**: Soft cool-slate (`#F1F5F9`) light theme and Deep Midnight Navy (`#0B1120`) dark theme with persistent `localStorage` state.
- **Interactive Command Palette (`⌘K` / `Ctrl+K`)**: Keyboard-accessible quick actions to navigate sections, copy email, download resume, and toggle themes.
- **Interactive Competency Context Inspector**: Hover or click any of the 30+ technical skills to inspect real-world production usage.
- **Role Focus Lens Switcher**: Switch between *MarTech & CRM*, *Software & QA*, and *Workflows & API* perspectives.
- **Project Architecture Case-Study Modal**: Detailed specification modals for *Yathartha Connect*, *Q Samriddhi*, and *Sentiment Analysis on "X"*.
- **Live New Delhi Clock (`IST`) & One-Click Copy**: Real-time `UTC+5:30` clock and instant clipboard copy with toast notifications.
